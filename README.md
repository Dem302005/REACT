# robot-task-planner

Панель планування завдань роботизованих платформ (React, практична робота №4, варіант 6).

Односторінковий застосунок: React 17, React Router (HashRouter), хуки useState/useEffect, Context API, асинхронні запити fetch до API (JSONPlaceholder).

Запуск: відкрити `index.html` у браузері або увімкнути GitHub Pages (Settings, Pages, гілка main, папка root).
